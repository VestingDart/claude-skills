# AI-Merkmale und was stattdessen

Checkliste für Schritt 4. Jeder Eintrag: das Merkmal, warum es auffällt, und Richtungen für
Ersatz. Die Ersatzideen sind Anregungen, keine neuen Defaults. Was passt, entscheidet der Brief.

## Farbe

| Merkmal | Warum es auffällt | Stattdessen |
|---|---|---|
| Lila-/Indigo-Blau-Verlauf (`from-indigo-500 to-purple-600`) | Der häufigste "modern"-Wert überhaupt | Farbe aus dem Gegenstand ableiten (Material, Ort, Logo, Epoche) |
| Dunkles Slate (`#0f172a`) mit Neon-Akzent und Glow | Standard-"Tech-Dark-Mode" | Wenn dunkel, dann mit eigener Tönung (Tinte, Nacht, Schiefer mit Wärme) |
| Verlaufstext in Überschriften | Effekt ohne Aussage | Volltonfarbe, Kontrast über Größe und Gewicht |
| Tailwind-Grauskala unverändert | Erkennt man an den exakten Werten | Eigene Neutraltöne, leicht zur Akzentfarbe getönt |
| Zufällige Blob-/Mesh-Verläufe im Hintergrund | Füllt Leere, die das Layout lösen sollte | Ruhiger Grund, Struktur über Raster, Linien, Bilder |

## Schrift

| Merkmal | Warum es auffällt | Stattdessen |
|---|---|---|
| Inter (oder System-UI) für alles | Default jedes Templates | Eine Schrift mit Charakter passend zum Brief, Paarung Display + Text |
| Die neuen "kreativen" Defaults: Space Grotesk, Instrument Serif, DM Sans, Playfair | Zweite Welle AI-Look | Weniger abgenutzte Familien suchen, Wahl begründen |
| Alle Überschriften gleich gewichtet, kaum Größenunterschied | Keine Hierarchie | Klare Typo-Skala mit deutlichen Sprüngen |
| Alles zentriert gesetzt | Template-Reflex | Linksbündig als Grundfall, Zentrieren nur gezielt |

## Layout

| Merkmal | Warum es auffällt | Stattdessen |
|---|---|---|
| Abfolge: zentrierter Hero → Logo-Leiste → 3 Feature-Karten → Testimonials → CTA-Band → Footer | Die SaaS-Schablone | Reihenfolge nach dem, was Besucher wirklich zuerst brauchen |
| Drei (oder sechs) gleich große Karten mit Icon oben | Gleichgewichtung, wo Gewichtung nötig wäre | Wichtigstes groß, Rest knapper; Liste, Tabelle, Text statt Karten |
| Jede Sektion gleich hoch, gleicher Abstand, gleicher Aufbau | Monotoner Rhythmus | Abwechslung in Dichte und Breite, asymmetrische Raster |
| Badge/Pill über dem Hero ("✨ Neu: ...") | Fester Bestandteil der Schablone | Weglassen oder durch echte Info ersetzen |
| Zwei Buttons nebeneinander im Hero (primär + "Learn more") | Reflex | Eine klare Handlung |

## Oberflächen und Effekte

| Merkmal | Warum es auffällt | Stattdessen |
|---|---|---|
| Glassmorphism (`backdrop-blur`, halbtransparente Karten) | Effekt-Default | Volle Flächen, klare Kanten |
| `rounded-2xl` / große Radien an allem | Einheitsweich | Radius aus dem Brief: scharf, klein, oder gezielt rund, aber konsistent |
| Weiche große Schatten (`shadow-xl`) überall | Tiefe ohne Grund | Linien, Flächenfarben, harte Schatten nur wenn passend |
| Glow, Partikel, schwebende 3D-Objekte | Deko statt Inhalt | Echte Bilder, Screenshots, Material aus dem Projekt |
| Fade-in-up-Animation an jeder Sektion | Scroll-Animation von der Stange | Wenig Bewegung, und wenn, dann mit Bedeutung |

## Icons und Bilder

| Merkmal | Warum es auffällt | Stattdessen |
|---|---|---|
| Lucide/Heroicons im farbigen Rundquadrat vor jedem Feature | Template-Signatur | Icons nur wo sie Orientierung geben, oder Zahlen, Bilder, Typo |
| Emojis in Überschriften und Listen (🚀 ✨ ⚡) | Sofort als generiert erkennbar | Weglassen |
| Generische Stock-/AI-Illustrationen, abstrakte 3D-Formen | Austauschbar | Echte Screenshots, Fotos, eigene einfache Grafik |

## Text

| Merkmal | Warum es auffällt | Stattdessen |
|---|---|---|
| "Unlock", "Elevate", "Seamless", "Supercharge", "Revolutionize", "Next-level", "Erlebe ..." | Marketing-Leerformeln | Konkret sagen, was es ist und kann |
| Dreier-Aufzählungen ("Schnell. Sicher. Einfach.") | Rhythmus-Reflex | Eine echte Aussage |
| Erfundene Zahlen ("10.000+ zufriedene Nutzer"), Testimonials, Kundenlogos | Irreführend auf echten Seiten | Echte Daten oder markierte Platzhalter |
| Lorem ipsum oder austauschbarer Fülltext | Zeigt nicht, wie die Seite mit echtem Inhalt wirkt | Realistischen Inhalt zum Gegenstand schreiben |
| Gedankenstriche überall, Doppelpunkt-Überschriften ("Community: Gemeinsam stark") | Typische Generierungs-Muster | Normal formulieren |
